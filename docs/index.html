How to Add It to Your Stack

In Fastify, register the plugin once. It decorates fastify.universalContent so your existing /sitemap.xml route can pull pre-cached XML chunks with only 2 lines of code:

src/routes/sitemap.route.ts (Host App) TypeScript 
import { mergeSitemapUrlsets } from '@crispice/universal-content/seo';

// Your existing sitemap route remains the boss:
fastify.get('/sitemap.xml', async (request, reply) => {
  // 1. Get your existing products/items as usual
  const products = await fastify.db.product.findMany();
  const baseXml = buildSitemapXml(products, 'murageh.co.ke');

  // 2. Fetch pre-cached blog XML chunk from plugin (< 0.05ms)
  const blogChunk = await fastify.universalContent.getSitemapXmlChunk({
    baseUrl: 'https://murageh.co.ke',
  });

  // 3. High-speed, non-destructive splice right before </urlset>
  const finalXml = mergeSitemapUrlsets(baseXml, blogChunk);

  return reply.type('application/xml').send(finalXml);
});

In Next.js App Router, use React Server Components and on-demand ISR revalidation tags:

app/blog/[slug]/page.tsx (Server Component) TypeScript / TSX 
import { getNextDocBySlug } from '@crispice/universal-content/next';
import { notFound } from 'next/navigation';

export default async function BlogPostPage({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params;
  
  // Fetches from local Markdown or Headless WordPress
  const post = await getNextDocBySlug({ contentDir: './content' }, 'blog', slug);
  if (!post) notFound();

  return (
    <article className="prose max-w-3xl mx-auto py-12">
      <h1>{post.title}</h1>
      <div dangerouslySetInnerHTML={{ __html: post.contentHtml }} />
    </article>
  );
}

In Vite applications, import virtual modules directly in memory with instant sub-10ms HMR:

src/App.tsx TypeScript / JSX 
// Dynamic virtual content generated in RAM by Vite compiler
import posts from 'virtual:content/blog';

export function BlogList() {
  return (
    <div className="grid gap-4">
      {posts.map((post) => (
        <a key={post.slug} href={"/blog/" + post.slug} className="card">
          <h2>{post.title}</h2>
          <p>{post.excerpt}</p>
        </a>
      ))}
    </div>
  );
}
